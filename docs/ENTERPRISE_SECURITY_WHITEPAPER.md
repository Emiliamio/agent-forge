## 2. 金融级多租户数据隔离机制 (AST AST-Level Isolation)

* **技术实现**：基于 `TenantLineInnerInterceptor` 在 SQL 编译期对抽象语法树 (AST) 进行强校验。
* **零越权保证**：无论是 `SELECT`、`UPDATE`、`DELETE` 还是多表 `JOIN` 子查询，底层自动拼接 `AND tenant_id = :current_tenant_id`。
* **实测认证**：通过 `TenantIsolationTest` 单元测试套件，跨租户查询越权测试用例拦截率达 100%。

## 3. 金融级 PII 敏感信息脱敏与 DLP 数据防泄漏 (Data Loss Prevention)

在用户输入 Prompt 发送给第三方外部大模型（如 DeepSeek/OpenAI）之前，系统内置的 `PiiMaskingService` 自动执行实体抽取与掩码替换：

| 实体类型 | 原始输入 | 发送给 LLM 的脱敏文本 | 模型返回后逆向还原结果 |
| :--- | :--- | :--- | :--- |
| **手机号** | `13812345678` | `[PHONE_1]` | `13812345678` |
| **身份证号** | `110101199003072345` | `[IDCARD_1]` | `110101199003072345` |
| **银行卡号** | `6222021234567890123` | `[BANKCARD_1]` | `6222021234567890123` |

## 5. 等保三级合规对照表

* **身份鉴别 (S3A1)**：支持多因子认证 (MFA) 与企业统一 SSO 登录。
* **访问控制 (S3A2)**：基于角色的访问控制 (RBAC: OWNER/ADMIN/EDITOR/VIEWER) + ACL 知识库行级权限过滤。
* **安全审计 (S3A3)**：全量操作日志与 Token 流水保留周期 $\ge 180$ 天，支持日志防篡改归档。
* **数据保密性与完整性 (S3A4)**：API Key SHA-256 加盐存储，向量索引与文本内容隔离存储。
