## 4. 架构真实性与同义词边界透明说明

1. **字面覆盖自然提问 (1~18 题)**：依托 CJK 2-gram 倒排索引与启发式重排，在真实 50+ 切片候选池中实测 Recall@5 达 100%，稳定满足企业交付硬门禁；
2. **离线同义改写边界 (19~20 题)**：在未配置商用 Dense Embedding 外部 Key 的离线环境下，系统退化为确定性稠密表征，无法跨词泛化（如“酒店”泛化至“住宿”）。此为透明公布的工程边界，绝不以假分数掩盖；
3. **生产增强建议**：商业化部署时仅需在平台控制台接入通用商用向量模型（如 text-embedding-v3 / DashScope），语义召回率将自动提升至全覆盖。
