# ADR 0003: 免登公开挂件安全隔离与访问边界

## 状态
已接受 (Accepted) - 2026-10-20

## 背景与上下文
AgentForge 支持将智能体以 Web Widget 形式嵌入第三方网站或公开门户供终端用户免密对话（`/api/public/agents/{id}/chat`）。然而，免登入口直接面向公网匿名流量，存在极高安全风险：
1. **未授权越权访问**：匿名攻击者可能随意遍历或盗刷未公开的内部私有智能体；
2. **凭证伪造与凭证泄露**：若未区分公网访问凭证与租户内部密钥，易造成管理权限越权；
3. **资源耗尽攻击 (DDoS/Token Exhaustion)**：匿名爆破与高频提问将迅速耗尽企业 LLM 账户余额；
4. **工具滥用风险**：普通公开访客可能触发具备写操作（如执行代码、调用内部 CRM API）的敏感 Agent 工具。

## 决策内容
1. **多层免登安全访问控制协议**：
   - **智能体状态门禁**：仅当目标智能体设置 `public_enabled == 1` 时才允许通过挂件接口对话，默认关闭 (0)；
   - **挂件安全凭证隔离**：引入独立公网访问凭证（`public_token`），支持通过 HTTP 请求头 `X-AgentForge-Public-Token`（及向下兼容的 `X-Public-Token`）进行验签，与租户主 API Key 物理隔离；
2. **独立细粒度令牌桶限流**：
   - 挂件端点接入独立 Redis 分布式限流器（配置 `agentforge.widget.rate-limit-rpm: 30`），按客户端真实 IP 精准拦截，超频立即返回 HTTP 429 与标准 `RATE_LIMIT_EXCEEDED` 错误响应；
3. **防伪造真实 IP 解析锁**：
   - 通过 `ClientIpResolver` 强制校验证书代理白名单（`agentforge.security.trusted-proxies`，严格收敛至回环与真实反代），杜绝伪造 `X-Forwarded-For` 绕过限流；
4. **严格只读与危险工具屏蔽**：
   - 挂件会话强制限定为只读检索与问答；公开会话严禁挂载系统管理、工作流触发或敏感写权限插件；对话过程记录独立审计。

## 影响评估
- **收益**：公网匿名嵌入具备金融级安全防线，彻底防御未授权探测、Token 盗刷与工具滥用攻击；API 具备清晰的权限防御矩阵。
- **代价**：租户管理员在公开智能体前，必须显式在管理后台启用公开开关并妥善配置/分发挂件 Token。
