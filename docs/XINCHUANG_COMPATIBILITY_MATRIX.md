## 🔒 二、 核心信创适配特性

### 1. 纯 Java 内存向量降级引擎（老旧脱网机保障）
在部分无法安装现代 C 扩展库（如 `pgvector.so`）的老旧或深度脱网国产操作系统中，AgentForge 内置了纯 Java 编写的高性能余弦相似度内存 Top-K 向量搜索引擎，基于 Java 21 虚拟线程并行计算，无需任何本地 C/C++ 依赖即可完成高精度检索。

### 2. 东方通 / 金蝶天燕 Web 容器标准适配
工程遵循标准 Jakarta EE / Servlet 6.0 规范，提供标准的 War 包与独立 Jar 双模式，可直接热部署至政企机房统一集采的 **TongWeb 7.0/8.0** 与 **Apusic** 企业级应用服务器。

### 3. 国产大模型本地离线私有化对接 (Ollama / vLLM / 昇腾算力卡)
针对华为昇腾 (Ascend 910B) 及海光 DCU 等国产算力平台，AgentForge 原生提供标准兼容的 OpenAI 格式及 Ollama 原生协议驱动，支持与企业内网算力集群 0 延迟安全通信。
