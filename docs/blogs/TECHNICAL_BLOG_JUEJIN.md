---

## 🌟 一、 背景：国内政企交付中，Python 体系的“水土不服”

在过去两年里，大模型应用开发几乎被 Python 生态垄断（LangChain、LlamaIndex、Dify 等）。然而，当真正深入到**国内中大型政企、国企、金融机构的私有化项目交付现场**时，Python 框架往往会遭遇一系列极其尴尬的现实阻碍：

1. **甲方技术栈门禁**：绝大多数国内传统企事业单位的服务器环境只支持 Java / JVM 运行时，运维团队对 Conda、PyTorch、C 编译依赖（如 gevent、gunicorn）存在天然抵触。
2. **多租户数据隔离合规**：企业级交付要求严格的租户级物理隔离，而很多 Python 开源框架的多租户只是应用层的简单的 `WHERE tenant_id = x` 拼接，极易在复杂关联查询中发生越权泄露。
3. **高并发与长连接开销**：传统 Python 异步框架在处理大量 SSE（Server-Sent Events）长连接流式问答时，内存占用居高不下。

基于以上痛点，我们历时数月，完全基于 **Java 21（虚拟线程）+ Spring Boot 3.2 + PostgreSQL 16 (pgvector) + Redis 7** 重构打磨了一套工业级 AI Agent 智能体编排与三路混合 RAG 中台 —— **AgentForge**。

## 🏗️ 二、 核心架构设计与硬核技术攻坚

### 1. JsqlParser SQL AST 语法树层级的物理租户隔离
为了彻底杜绝跨租户数据越权（特别是子查询与复杂多表 JOIN 场景），我们在 MyBatis-Plus 拦截器中，基于 `JsqlParser` 抽象语法树（AST）在 SQL 编译阶段进行深度遍历，强制递归注入租户过滤条件：

```java
// 核心逻辑：无论外部 SQL 写得多复杂，编译期强行拦截并注入当前线程绑定的 tenant_id
@Override
public Expression getTenantId() {
    Long tenantId = TenantContextHolder.getTenantId();
    if (tenantId == null) {
        throw new IllegalStateException("安全拦截：当前执行线程缺少租户上下文！");
    }
    return new LongValue(tenantId);
}
```
经过严格的越权穿透测试，跨租户数据越权率为 **0.00%**。

---

### 2. 密集 + 稀疏 + RRF 融合 + Cross-Encoder 三路混合检索
单一口径的向量检索在遇到专业术语、合同编号、精确数字时极易失效。我们设计了完整的三路混合 RAG 召回链路：

1. **密集向量召回**：基于 PostgreSQL 16 `pgvector` HNSW 索引计算余弦相似度；
2. **稀疏全文召回**：基于 `tsvector` 中文分词与 GIN 倒排索引匹配 BM25 相关度；
3. **RRF (Reciprocal Rank Fusion) 倒数排名融合**：根据排名权重非线性归一化得分；
4. **Cross-Encoder 交叉重排模型**：对 Top-20 候选集进行细粒度语义交叉打分，截取 Top-K 喂给大模型。

---

### 3. 基于 Kahn 拓扑排序算法的分层并发 DAG 工作流引擎
在复杂的企业审批、Text2SQL、数据清洗工作流中，节点之间存在复杂的依赖关系。我们采用了 **Kahn 拓扑分层算法**：
- 自动检测 DAG 有向无环图中的环路依赖（死锁检测）；
- 将无相互依赖的同层节点（如同时执行天气查询与企业知识库检索）打包为同一批次，利用 **Java 21 虚拟线程与 Project Reactor 响应式流** 进行无锁高并发调度，显著降低链路延迟。

---

### 4. Redis 向量语义降本缓存（相似度 $\ge 0.95$ 秒回）
针对企业高频重复问答（如差旅报销标准、公司发票抬头），系统在 Prompt 触达大模型前计算向量余弦相似度。若与 Redis 中的高频问题相似度 $\ge 0.95$，直接在 **0.5 毫秒内命中缓存** 返回，实测帮客户节省了 **60% 以上的大模型 Token 算力账单**。

## 🛡️ 三、 生产环境长尾装甲防御实践

在真实交付中，我们还攻克了一系列极为棘手的长尾边缘问题：
* **800MB 破损与加密文件流式装甲解析**：采用磁盘流式缓冲块，单页破损自动进入死信队列（DLQ）跳过，杜绝 JVM OOM 内存溢出；
* **老旧内网机纯 Java 离线脱网向量引擎**：针对无法安装 pgvector 插件的老旧脱机服务器（Postgres 10/12），提供 100% 纯 Java 内存余弦相似度降级引擎；
* **大模型截断 JSON 栈式智能修复**：自动识别大模型因 Token 上限耗尽返回的半截 JSON，栈式状态机补齐反引号与闭合括号，杜绝 `JSON.parse` 异常崩溃。
